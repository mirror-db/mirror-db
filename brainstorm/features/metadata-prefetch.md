# 元数据 Prefetch

## 目标

根据 mirrors 接口下发的 policy，自动刷新指定 mirror 路径的元数据，使 Releases、PyPI 主目录等资源保持更新，并为目录合成和哈希预判提供新数据。

## 非目标

- 不因递归元数据解析预热全部包体。
- 不对未标记的路径默认启用全仓库 prefetch。

## 交互

- policy 标记需要自动保持更新的 mirror 路径。
- relay 按策略刷新这些资源；APT 等解析器可继续处理其引用的元数据。
- 普通内容仍在真实请求 MISS 时按需获取。

## 实现

- prefetch 仅递归元数据，是否预热引用内容不属于本功能。
- 刷新周期、条件请求、并发限制、失败重试及递归规模边界待定。
- PyPI 主目录的自动更新不意味着递归抓取所有包页面，除非后续另有明确规则。

## 验收

1. 被标记路径能无需客户端请求而自动更新，未标记路径不启动 prefetch。
2. APT 递归只获取元数据引用，不自动获取包体。
3. 更新结果可被 APT 目录合成和 relay 哈希预判使用。
4. 调度、失败与资源占用边界在实现前形成明确配置。
